THE MOCK

Everything above is the theme, not a screenshot. The panels, the hairlines, the traffic lights and the sliding server rail are drawn with the same tokens the CSS files ship with, so switching a build up there is switching it in Discord.

Hover the strip on the far left to open the server rail, and hover the window controls to see their glyphs.

INSTALL

Settings, then Themes, then Open Themes Folder. Drop one file in and tick it. On Windows the folder is %APPDATA%\Vencord\themes, or %APPDATA%\BetterDiscord\themes.

Enable one build at a time. Two of them loaded together fight over the same elements. Vencord rereads the file whenever it changes on disk, so you can keep it open in an editor while you tune it.

BUILDS

AerogelDark.theme.cssThe reference build. Matte black, frosted panels, slow aurora.
AerogelLight.theme.cssMaterial inverted: white glass, depth from dark ink instead of white film.
AerogelViolet.theme.cssMatte black with an amethyst cast. Built for 505h.
AerogelDarkFlat.theme.cssNo blur, no animation, opaque panels. For weak GPUs and remote desktops.
AerogelLightFlat.theme.cssThe same treatment on the light build.

KNOBS

Each file opens with a :root block. Edit a value, save, done.

--gmd-accentPills, selected channel, links. Change --gmd-accent-rgb with it or the translucent states will not follow.
--gmd-guildbar-autohide1 slides the server rail, 0 pins it open.
--gmd-auroraStrength of the drifting glow. 0 removes it, and so does --gmd-grain.
--gmd-bgThe frame behind the glass. Any gradient, colour or image URL.
--gmd-panel-gapSpace between the floating tiles. Radius and blur sit next to it.

UPDATES

Discord ships class names with a rotating hash, like sidebarList__5e434. Aerogel never matches a full hashed name, only the stable fragment, so a hash change costs nothing.

If Discord renames a component outright, one section goes plain while the rest keeps working. Find the new fragment in DevTools, replace the old one in src/ and rebuild.
